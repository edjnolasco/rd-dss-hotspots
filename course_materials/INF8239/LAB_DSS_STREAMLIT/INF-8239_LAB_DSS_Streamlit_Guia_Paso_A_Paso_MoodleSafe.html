DSS para priorización territorial con Streamlit

Guía del estudiante · Construcción paso a paso

Propósito. Construir una aplicación que transforme datos históricos en un ranking de prioridad, explique la regla aplicada y presente recomendaciones para revisión humana.
Importante. Este laboratorio es formativo y no agrega puntuación al programa. Los resultados no constituyen órdenes de intervención: apoyan a una persona responsable de decidir.

1. Resultados de aprendizaje

  • Diferenciar una predicción, un tablero y un DSS.
  • Aplicar separación temporal sin utilizar información futura.
  • Comparar un baseline con un modelo candidato.
  • Convertir una predicción en score, categoría, regla y recomendación.
  • Construir una interfaz Streamlit y verificar el núcleo con pruebas.

2. Arquitectura que construiremos

ComponenteResponsabilidad
DatosCargar y validar provincia, año y fallecidos.
ModeloEstimar el valor del período siguiente.
Reglas DSSAsignar prioridad, conservar la trazabilidad y recomendar una acción.
StreamlitPermitir configurar, ejecutar, consultar y descargar resultados.

required = {"provincia", "year", "fallecidos"}

7. Paso 05 · Crear características temporales

group = out.groupby("provincia", group_keys=False)["fallecidos"]
out["fallecidos_prev_1"] = group.shift(1)
out["fallecidos_prev_2"] = group.shift(2)
out["delta_abs"] = out["fallecidos"] - out["fallecidos_prev_1"]
out["rolling_mean_3"] = (
    group.rolling(3, min_periods=1).mean()
    .reset_index(level=0, drop=True)
)
out["target_next"] = group.shift(-1)

Discusión: target_next representa el valor que se intentará predecir. Las filas del último período no poseen ese valor y no deben usarse como ejemplos etiquetados.

Comprobación: python -m pytest -q -k features.

8. Paso 06 · Separar el tiempo correctamente

test_year = int(sorted(trainable["year"].unique())[-1])
train = trainable[trainable["year"] < test_year].copy()
test = trainable[trainable["year"] == test_year].copy()

No utilice una partición aleatoria para este caso. El modelo debe entrenarse con el pasado y evaluarse con un período posterior.

Comprobación: python -m pytest -q -k temporal.

Calcule MAE, RMSE y R² para ambos. El modelo candidato no se considera útil solo por ser más complejo: debe compararse con el baseline.

10. Paso 08 · Construir el motor de reglas

if score >= 0.80:
    return Decision(
        "Alta prioridad",
        "R1: score >= 0.80",
        "Priorizar revisión e intervención; validar recursos disponibles.",
    )

if score >= 0.60 and delta_abs > 0:
    return Decision(
        "Vigilancia preventiva",
        "R2: score >= 0.60 y tendencia creciente",
        "Monitorear la evolución y preparar medidas preventivas.",
    )

Cada salida debe conservar tres elementos: categoría, regla aplicada y recomendación. Una etiqueta sin explicación no cumple la función de trazabilidad.

Comprobación: python -m pytest -q -k rule.

11. Paso 09 · Calcular score y ranking

latest["prediccion"] = np.maximum(model.predict(latest[FEATURES]), 0.0)
low = latest["prediccion"].min()
high = latest["prediccion"].max()
latest["score_riesgo"] = (
    0.5 if high == low
    else (latest["prediccion"] - low) / (high - low)
)
ranking = latest.sort_values("score_riesgo", ascending=False)

El score expresa prioridad relativa dentro del conjunto analizado. No debe interpretarse automáticamente como una probabilidad.

Comprobación: python -m pytest -q -k ranking.

13. Paso 11 · Construir la aplicación Streamlit

Abra app.py e incorpore, en este orden:

  1. st.set_page_config, título y propósito.
  2. Carga opcional de CSV y selector Top-K.
  3. Botón para ejecutar.
  4. Manejo de excepciones.
  5. Comparación de métricas.
  6. Tabla y gráfico del ranking.
  7. Consulta de regla y recomendación por provincia.
  8. Advertencia de supervisión humana.
  9. Descarga del resultado.
@st.cache_data(show_spinner=False)
def execute_pipeline(file_bytes):
    return run_pipeline(file_bytes)

uploaded = st.file_uploader("Dataset opcional", type=["csv"])
top_k = st.slider("Cantidad de provincias", 3, 15, 10)

if st.button("Ejecutar análisis", type="primary"):
    result = execute_pipeline(uploaded.getvalue() if uploaded else None)
    st.dataframe(result["ranking"].head(top_k), hide_index=True)

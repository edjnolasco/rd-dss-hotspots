# Proyecto inicial · Laboratorio DSS con Streamlit

Autor del material: **Edwin Ramón José Nolasco**

1. Cree y active `.venv`.
2. Instale `requirements.txt`.
3. Ejecute `pytest -q`: al inicio las pruebas deben fallar.
4. Complete los TODO de `src/dss.py`.
5. Complete `app.py`.
6. Repita `pytest -q` hasta obtener seis pruebas aprobadas.
7. Ejecute `streamlit run app.py`.

No copie la solución completa antes de intentar cada paso. Registre un commit al terminar cada punto de control.
